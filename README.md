# Health Tracker

A desktop application to track workouts and overall health metrics.

## Features

- **Exercise Logging**: Track cardio and lifting exercises with detailed parameters.
- **Goals System**: Set a goal for the future and the program will tell you when you have achieved it.
- **Progress Monitoring**: View history of exercises.
- **Customizable Interface**: Supports different modes for cardio and strength training.

## Technologies

- **Language**: C#
- **Framework**: .NET (Windows Forms)
- **Database**: SQLite
- **Tools**: Visual Studio
